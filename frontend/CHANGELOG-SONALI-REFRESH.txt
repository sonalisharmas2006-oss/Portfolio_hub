Run locally:
1. Open the frontend folder in VS Code.
2. Run: npm install
3. Copy .env.local.example to .env.local and set NEXT_PUBLIC_API_BASE_URL to your backend URL.
4. Run: npm run dev

The frontend expects the existing FastAPI backend API. This bundle contains frontend files only.
